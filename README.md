# XLPluginTranslator

一键浏览并翻译 Dalamud 插件仓库的英文简介与说明。

## 功能

- 自动抓取 Dalamud 官方仓库与第三方仓库的插件列表
- 调用公益免费大模型，将插件简介翻译为简体中文
- 本地缓存翻译结果，避免重复请求
- 支持搜索、过滤、批量翻译、单独翻译

## 安装

1. 在游戏中输入 `/xlsettings` 打开设置
2. 切换到 **插件/第三方插件** 标签页
3. 在 **第三方插件仓库** 区域粘贴以下链接并保存：
 https://cdn.jsdelivr.net/gh/HanaSi0/XLPluginTranslator@main/repo.json
